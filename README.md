# E-Library-Management-System

Designed and implemented an Electronic Library Management System database using MySQL.

• Performed requirement analysis and database planning.
• Created an Entity Relationship Diagram (ERD) to model books, authors, members, and borrowing operations.
• Converted the conceptual design into a logical database schema with primary and foreign keys.
• Implemented the physical database design using SQL, including tables, constraints, and indexes.
• Developed SQL queries to manage book borrowing, returns, and availability tracking.

Skills: MySQL, SQL, Database Design, ER Modeling, Relational Databases, System Analysis.
